### 3. Grievance Redressal Protocol & Timelines
We have established a robust, ticket-backed customer dispute mechanism:

```
┌────────────────────────────────────────────────────────────────────────┐
│                   MANDATORY GRIEVANCE ESCALATION SLA                   │
├────────────────────────────────────────────────────────────────────────┤
│ 1. FILING (T = 0 Hours)                                                │
│    Consumer files dispute at support@goatednation.com or via /support  │
│                                                                        │
│ 2. STATUTORY ACKNOWLEDGMENT (T ≤ 48 Hours)                             │
│    System issues unique Grievance Reference ID (GN-TK-XXXX)            │
│    and assigns dedicated support associate                            │
│                                                                        │
│ 3. INVESTIGATION & EVIDENCE REVIEW (T ≤ 7 Business Days)               │
│    Logistics courier weight logs, CCTV packing footage, or defect      │
│    photographs audited by compliance desk                              │
│                                                                        │
│ 4. FORMAL REDRESSAL & SETTLEMENT (T ≤ 30 Days)                         │
│    Replacement manifested, 100% refund executed via Razorpay, or       │
│    formal resolution note issued                                       │
│                                                                        │
│ 5. STATUTORY ESCALATION (If unresolved)                                │
│    National Consumer Helpline (NCH): consumerhelpline.gov.in / 1915    │
└────────────────────────────────────────────────────────────────────────┘
```

If you are dissatisfied with our resolution, you have the statutory right under Indian law to register your complaint on the **National Consumer Helpline (NCH)** via `consumerhelpline.gov.in` or call toll-free `1915`.
